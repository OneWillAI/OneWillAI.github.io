THE PRODUCT

Retcon agent actions

OneWill lets you observe, control, handoff, and retcon agent actions. It provides these capabilities through a gaming-inspired overlay for your regular coding agents (codex, claude, agy), no source code changes or agent modifications required.

Behind the scenes, OneWill's technology interposes agent actions with database magic (see blog for details) to ensure that before any action runs, it must either be reversible or explicitly approved by you. We provide peace of mind and broaden the scope of work that you can hand off to agents.

Why retcons matter
  1. Irreversible actions. The agent assumed a delete API was staging-only. It was not. Our retcon system autosaves before irreversible actions, and forces sign-off when an action would prevent rollback. HN
  2. Catastrophic context amnesia. The agent was told to never delete emails, but compaction made it forget. TechCrunch
  3. Ordinary agent failures. Even if the agent tells you that "you're absolutely right", it is little condolence for whatever chaos it left behind.
